# C++ Calculator

A simple command-line calculator written in C++.

## Features
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Input validation for numbers
- Invalid operator detection

## Usage
1. Enter the first number.
2. Enter the second number.
3. Choose an operator (`+`, `-`, `*`, `/`).
4. View the result.

## Compilation

```bash
c++ main.cpp -o calculator
```

## Run

```bash
./calculator
```

## Technologies
- C++
- Standard Library (`iostream`, `string`)
